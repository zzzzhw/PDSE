# KronoDroid real-device temporal benchmark

This directory is generated by `experiments/prepare_kronodroid.py` from the
public real-device CSV archives in the first author's KronoDroid repository.

- Dataset repository: https://github.com/aleguma/kronodroid
- Pinned source commit: `c6ec342167bc449967a802824d068900ac8120c5`
- Dataset paper: https://doi.org/10.1016/j.cose.2021.102399
- Initial training window: 2011-01 through 2011-12
- Prequential test window: 2012-01 through 2012-12
- Timestamp: `HighestModDate`

The converter removes SHA-256 values that have conflicting binary labels and
excludes package identity, hashes, timestamps, family labels, VirusTotal
scanner counts/detection ratios, submission counts, and contacted-IP counts
from model input. Missing or negative feature values are replaced with zero,
then non-negative count features are transformed with `log1p` and standardized
using statistics fitted only on the 2011 training data. Features constant in
the training window are removed.

The generated `.npz` and manifest files are intentionally ignored by Git. Run:

```bash
python experiments/prepare_kronodroid.py
```
